## Project conventions (Phyto Elements)

- Read `README.md` first: stack, structure, theme, forms.
- All site copy lives in `src/content/*` and is read only through `src/lib/content.ts` (async, CMS-ready). Never hard-code product data in components.
- Styling: use theme tokens only (`bg-paper`, `text-heading`, `bg-accent`, `text-accent-text`, `.band`, `.card` …). No raw hex colours in components; colour routes live in `src/styles/themes.css`.
- Colour: tokens live in `src/styles/themes.css` (`:root` + `[data-theme="verdan"]`); the Logo look overrides them in `logo.css`. Depth/typography effects live in `src/styles/polish.css`.
- Buttons: `.btn` (primary, accent fill) and `.btn btn-ghost` (outline in `--accent-text`). Keep this consistent in every theme.
- Positioning: Phyto Elements sources extracts from qualified producers, tests every lot, and sells under its label only lots that pass. Quality is shown through rigorous, very high testing standards. The page and nav label stay "Manufacturing & Quality" (/manufacturing), but manufacturing is not the headline and the Garcinia plant is not a focus. Use "lot", not "batch".
- Never state how many products/extracts there are (no "six extracts", "five more", "all six"): the client keeps adding products. Use range wording ("every extract", "our range") and render lists from `products.ts`.
- Product codes (PE-01 …) stay in `products.ts` as internal ids only; the client does not want them shown anywhere on the site (cards, lightbox, hero, tables, structured data).
- Content governance: never add unverified specs, certifications, capacities, customer names or health claims. Product `spec` values are the client's representative specifications (Nov 2026; Bakuchiol from published supplier data); unset fields show "Shared on request". No packing, lead-time or batch/lot-number fields on product pages.
- Contact: the only public email is info@phytoelements.in (one exception, client Nov 24: the Grievance Officer's ashwin.j@phytoelements.in, on the Privacy Policy only); the address is "Hyderabad, India"; the company name is "Phyto Elements". No review notes, placeholders or pre-production text on pages (ReviewNote is no longer used).
- Quality wording: say lots are tested to "recognised global quality standards" (and beyond) — never "our own standards/specification".
- Motion preference: the site does NOT follow the OS `prefers-reduced-motion` (client wants motion on every device, incl. Macs with Reduce motion on). Use `calmMotion()` / `html.pe-calm` from `lib/motion-pref.ts`; the footer "Reduce motion" toggle was removed (client, Nov 19), so motion is always on; a stored calm preference is cleared at boot.
- No illustrations: use product photos (preloader product row, cards, carousel). Exception the client wants kept: the leaf-to-Phyto-bottle art (`LeafDropArt`) in the preloader and the page transition. `botanicals/Illustration` is only the fallback inside `ProductOrb` for a product added without a photo.
- Motion: client components only; respect the site motion preference (`calmMotion()`); content must be visible at rest (no opacity: 0 waiting on scroll). Clean up GSAP / ScrollTrigger (`ctx.revert()`). Effects must clean up (client navigation).
- Motion components: preloader (`motion/Preloader`, CSS only, every full load), hero (`hero/SpecimenHero`, canvas), wave edges (`.wave-top`). Styles live in `src/styles/motion.css`.
- Colour route (Nov 24): only R10 "Verdan light" (`verdan`, `defaultTheme` in `src/config/site.ts`) is kept. Routes R01–R09, the route switcher, /compare and per-page route themes were removed on Abhi's instruction (recoverable from git history before Nov 24).
- Verdan builds on `src/styles/lab.css` (shared scene rules, `--lab-*` / `--specimen-*` tokens) plus `verdan.css`; `hero/HeroScene.tsx` draws the hero dial.
- Scrolling (Nov 24, client): the browser's standard scrolling everywhere — no smooth-scroll library (Lenis/GSAP removed), no full-screen panels or circle reveal (PanelScroll removed), no scroll-triggered or scroll-driven animations (`Reveal` is now a plain wrapper; CSS `animation-timeline` rules removed), and no fallback mode (fx-guard removed). Do not add scroll effects. Click/navigation animations stay: the leaf-to-bottle page transition (`motion/RouteTransition`), the preloader on full loads, carousels, and autoplaying pieces (hero lots, SealStepper). New page sections are `<section>` elements with a `.wrap` child.
